🏗️ Panduan Transisi ke Fullstack Monorepo

Struktur modul HTML ini dirancang agar siap dipetakan 1-to-1 ke dalam arsitektur Monorepo Next.js + NestJS/Hono + Prisma:

Turborepo Architecture
🌐 apps/web (Storefront & Portal)
Mengonversi Tema A, B, C ke dalam Next.js App Router dengan Dynamic Theme Provider (apps/web/app/(shop)/layout.tsx) dan Customer Portal (apps/web/app/portal/page.tsx).
⚡ apps/admin (Super Admin ERP)
Mengonversi seluruh manajemen HPP, stok kawat bulu, pesanan, CS Hub, dan titik COD Google Maps ke dashboard admin Next.js / TanStack Table.
🗄️ packages/database (Prisma & Schema)
Skema PostgreSQL untuk orders, products, materials_bom, warranty_claims, cod_points, dan chat_messages sesuai rancangan di PRD.md.
🛡️ packages/ui & shared-types
Penyatuan tokens warna CSS tema, komponen tombol garansi, stepper status pesanan, dan type safety TypeScript untuk seluruh monorepo.
